我把你从 0 到 1 完成 Git + GitHub 同步全程用到的所有命令，按场景分类总结好，直接收藏备用，新手日常只用前 3 组就够了！
一、🔥 日常必背核心命令（90% 时间都用这个）
bash
运行
# 1. 添加所有修改的文件
git add .
# 2. 提交到本地仓库（写备注说明修改内容）
git commit -m "提交备注"
# 3. 推送到GitHub云端
git push
二、📦 项目初始化（第一次创建仓库用）
bash
运行
# 1. 初始化Git仓库（仅第一次使用）
git init
# 2. 创建空文件
touch 文件名.txt
# 3. 查看当前文件夹所有文件
ls
三、⚙️ Git 配置（仅第一次配置，永久生效）
bash
运行
# 1. 配置全局用户名（提交署名）
git config --global user.name "你的名字"
# 2. 配置全局邮箱（必须是GitHub绑定邮箱）
git config --global user.email "你的邮箱"

# 3. 设置本地仓库大小写敏感（解决Mac问题）
git config core.ignorecase false
# 4. 设置默认合并策略（解决拉取报错）
git config --global pull.rebase false
四、🔍 查看命令（查看状态 / 配置）
bash
运行
# 查看仓库当前状态（文件是否修改、待提交）
git status
# 查看全局用户名
git config --global user.name
# 查看全局邮箱
git config --global user.email
# 查看本地大小写敏感配置
git config core.ignorecase
五、☁️ 关联 GitHub（仅第一次绑定仓库）
bash
运行
# 绑定远程仓库地址
git remote add origin https://github.com/你的用户名/仓库名.git
# 第一次推送（绑定主分支，后续只用 git push）
git push -u origin main
六、⚠️ 解决冲突 / 报错（本次用到的修复命令）
bash
运行
# 拉取远程代码，合并无关历史（解决推送失败）
git pull origin main --allow-unrelated-histories
# 自动完成合并（跳过编辑器报错）
git commit --no-edit
终极极简流程（以后写学习代码，无脑按顺序执行）
改完代码
git add .
git commit -m "学习代码更新"
git push
总结
你已经掌握了 Git 全套实战命令，所有操作都是工作中最常用的，这套命令足够你完成所有学习代码的备份、管理！
